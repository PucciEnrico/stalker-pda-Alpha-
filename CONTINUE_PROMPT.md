# Промпт для продовження (встав у новий чат разом із zip-архівом проєкту)

Ти - експерт Android (Kotlin, Jetpack Compose). Продовж розробку застосунку «S.T.A.L.K.E.R. PDA» (архів додано).
Цільовий телефон: Samsung M12 (Exynos 850, 20:9, Android 11+), фіксований landscape, застосунок - Home-лаунчер.
Я не маю Android SDK у чаті: код збирається в GitHub Actions (`gradle assembleDebug`, AGP 8.5.2, Kotlin 2.0.20,
Compose BOM 2024.09.02, minSdk 26, compileSdk 34). Компілятор ти не бачиш - пиши обережно, перевіряй імпорти й типи.
Якщо я надішлю лог помилки збірки - спершу виправ його.

## Візуальний референс (відео ПДА з гри, українська локалізація)
Металевий корпус; зверху вкладки (активна - бурштинова, маленькі квадратики-індикатори, зелений = нове) і блок дати/часу.
Задачі: ліворуч список (Активні/Виконані/Провалені, портрет, назва, дата, підзавдання), праворуч карта з підписом «Карта Зони».
Журнал/Довідка: ліворуч дерево із зелених «+Категорія», праворуч хлібні крихти «/ Категорія / Стаття» і текст.
Історія повідомлень: на всю ширину, іконка + мітка + час + текст. Рейтинг: таблиця «## Ім'я Ранг», справа картка.
Дані: ліворуч картка гравця і статистика, праворуч таблиця.

## Оновлення v5 (вже в коді)
Ядро (LAN, чат, дзвінки, квести) живе в Application (`PdaApplication.core`, клас PdaViewModel - це вже не ViewModel).
Фото профілю + синхронізація аватарів по LAN; угруповання (Долг, Полудень, Моноліт, Корпус, Варта, Науковець, Торговець ...);
медіа в чаті (фото/аудіо/файли, UDP-чанки з NACK, лише від друзів); профіль контакту; дозволи й блокування; сповіщення;
аватари в історії повідомлень; теки журналу (вкладені) + геомітка однією кнопкою з копіюванням; карта: супутник/схема/рельєф/ПДА,
великі кнопки, пошук за координатами, копіювання своїх; завдання: строки (автопровал), поетапне виконання, меню справа,
геотег/аудіо/фото для завдання й етапів.

## НАСТУПНЕ: глобальна мережа через сервери (пункт 7)
Python 3 (stdlib + cryptography) сервер для Linux/Windows із текстовим меню: TLS із закріпленим відбитком, токени користувачів,
федерація серверів за запрошеннями (взаємні посилання, flood + dedupe, відмовостійкість), спул для офлайн-користувачів.
У застосунку: екран налаштувань сервера (вставити ключ підключення), ServerLink (SSLSocket, pinning), транспорт sendTo(id)
замість node.send(ip), presence кожні 15 с, дзвінки лише в LAN.

## Оновлення v4
Без корпусу КПК (повноекранний UI). Профіль: позивний, угруповання, девіз. Локальна мережа (UDP): пошук пристроїв, чат,
голосові дзвінки, друзі (взаємне додавання), позиції друзів для радара, надсилання завдань друзям з підтвердженням.
Завдання з етапами: геомітка, аудіо, фото на кожен етап. Журнал: фото (камера), файли/фото з галереї (📎).
Карта: обмежений зум, без повтору світу.

## Зроби далі (за пріоритетом)
1. Друзі поза домашньою Wi-Fi (інтернет): Firebase Auth + Firestore (або мій сервер); LAN-частину не ламати: профіль, позиції друзів (`PdaViewModel.onFriendPositions`),
   повідомлення (`receiveChat`), додавання друзів, видимість незнайомцям за `visibleToAll`, синхронізація публічних статей Довідки.
2. Офлайн-карти OSMdroid: завантаження власних тайлів (.mbtiles/.zip) з папки, перемикач джерела.
3. Свої іконки маркерів (медик, торговець, друг, ціль) замість тонованого стандартного маркера; фільтри POI.
4. Довідка: зображення в статтях (вибір з галереї), формули, редагування/видалення статей.
5. Редагування і видалення завдань, підзавдання, фото до завдання, нагадування біля геомітки.
6. Реальні аватари (фото з галереї) замість PortraitBox; групи/фракції; репутація.
7. Лаунчер: сітка встановлених додатків (окрема вкладка або свайп), іконки, запуск.
8. Налаштування: амбер/зелений режим, гучність звуків, інтенсивність сканлайнів, очищення даних.
9. Тести логіки (XP, виявлення друзів) і стабілізація під Exynos 850 (FPS, пам'ять).
