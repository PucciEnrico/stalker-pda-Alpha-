# S.T.A.L.K.E.R. PDA (Android, Jetpack Compose)

Повноекранний інтерфейс ПДА для Samsung M12 (landscape). Вкладки: Задачі / Карта / Журнал / Історія повідомлень /
Контакти / Рейтинг / Дані / Довідка.

## Збірка
Android Studio (JDK 17): Open -> Build -> Build APK(s), або GitHub Actions (`.github/workflows/build.yml`).

## Локальна мережа
Телефони в одній Wi-Fi знаходять один одного (UDP 45454, голос 45455). «+ В ДРУЗІ» у профілі контакту
(додайте одне одного) відкриває чат з фото/аудіо/файлами, дзвінки, радар, завдання друзям.
Профіль контакту: натисни його аватар у чаті. ⚙ там - дозволи (дзвінки, фото, аудіо, файли) і блокування.
Повідомлення й дзвінки приходять сповіщеннями, навіть коли екран ПДА закритий (поки працює служба GPS).

## Дані
Фото профілю, теки журналу, завдання з етапами/строками зберігаються на телефоні.
