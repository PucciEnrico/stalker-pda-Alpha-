# Сервер S.T.A.L.K.E.R. PDA: інструкція

Сервер об'єднує користувачів ПДА по всьому світу: геопозиції, чат, фото/файли, завдання. Сервери можна
з'єднувати між собою, тоді вони утворюють одну спільну мережу. Якщо один сервер зламається, решта працює далі.

## 1. Що потрібно
- Комп'ютер або міні-сервер із Linux чи Windows, який увімкнений постійно.
- Python 3.8 або новіший.
- Доступ ззовні до порту сервера (за замовчуванням 8443/TCP): білий IP або проброс порту на роутері,
  або доменне ім'я (DDNS). Якщо білого IP немає, можна користуватися VPN-мережею на кшталт Tailscale/ZeroTier
  і вказувати адресу з неї.

## 2. Встановлення

### Linux
1) Скопіюй папку `server` на сервер.
2) Відкрий термінал у цій папці:  `chmod +x start.sh`  і  `./start.sh`
   (скрипт сам доставить потрібний пакет `cryptography`).

### Windows
1) Встанови Python з python.org. На першому екрані познач «Add Python to PATH».
2) Двічі клацни `start.bat`.

З'явиться текстове меню. Усе керування робиться ним.

## 3. Перше налаштування (один раз)
1) У меню натисни 8, потім 2 і введи адресу сервера: IP або домен, за яким до тебе зможуть підключитися.
2) За бажанням 8, потім 1: задай назву сервера. 8, потім 3: змінити порт.
3) Відкрий порт:
   - Linux (ufw):        `sudo ufw allow 8443/tcp`
   - Windows: «Брандмауер» -> Додаткові параметри -> Правила для вхідних підключень -> Створити правило -> Порт -> TCP 8443 -> Дозволити.
   - Роутер: проброс порту 8443 (TCP) на цей комп'ютер.
4) Запусти сервер: у меню 1. Видно рядок «сервер ... слухає порт», зупинити можна Ctrl+C.

Рекомендація: сервер тримати в одному вікні (`./start.sh --run` або `start.bat --run`), а меню для змін
відкривати в другому. Сервер підхоплює зміни (користувачі, сервери) сам протягом ~5 секунд.

## 4. Додати людину (користувача)
1) У застосунку людина відкриває: Контакти -> [⚙] -> «🌐 Сервер...». Там написано «Мій ID». Вона надсилає його тобі.
2) У меню сервера натисни 3, введи цей ID (і позивний для себе). Сервер покаже «Ключ підключення»: рядок `PDA1:...`.
3) Передай ключ людині безпечно (особисто, у закритому чаті). Показується один раз, у ключі токен доступу.
4) Людина в тому ж вікні натискає «📋 Вставити», потім «Підключити». Статус стане «підключено».

Видалити людину: пункт 4 меню (вона відключиться за кілька секунд, її нік звільниться).

## 5. З'єднати два сервери (А і Б)
Сервер А: меню 5, видасть запрошення `PDAS1:...` (одноразове). Передай його власнику сервера Б.
Сервер Б: меню 6, встав запрошення. Зв'язок встановиться сам (сервер Б має бути запущений).
Сервер А впізнає Б автоматично. Якщо в Б указана адреса (меню 8, потім 2), А теж сам підключатиметься до Б.
Коли будуть сервери В, Г тощо, повторюй те саме. Чим більше зв'язків між серверами, тим стійкіша мережа:
повідомлення йдуть будь-яким робочим шляхом, тож при поломці одного сервера відключаються лише його власні
користувачі, решта мережі працює. Меню 2 показує, з якими серверами є зв'язок. Меню 7 видаляє сервер зі списку.

## 5а. Унікальні позивні (нікнейми)
У всій мережі пов'язаних серверів не може бути двох однакових позивних (регістр не важливий). Хто зайняв нік першим,
той і володіє ним; другий у застосунку бачить червоне попередження у вкладці «Дані» й обирає інший нік сам.
- Людина, яка перевстановила застосунок, робить у «Дані» «⬇ Імпорт» зі своєї копії: вона повертає той самий ID, нік
  і ключ сервера, тому нік лишається її.
- Нік звільняється, коли власник змінює його або коли ти видаляєш користувача (меню 4). Меню 9 показує всі зайняті
  ніки та дозволяє звільнити нік вручну (наприклад, якщо людина загубила копію й перевстановила застосунок з нуля).
- Якщо два сервери були роз'єднані й там взяли однаковий нік, після відновлення зв'язку виграє той, хто зайняв
  його раніше; інший отримає повідомлення і обере інший нік.

## 6. Автозапуск
Linux (systemd): файл `/etc/systemd/system/pda.service`
```
[Unit]
Description=PDA server
After=network-online.target
[Service]
WorkingDirectory=/шлях/до/server
ExecStart=/usr/bin/python3 pdaserver.py --run
Restart=always
User=ТВІЙ_КОРИСТУВАЧ
[Install]
WantedBy=multi-user.target
```
Потім: `sudo systemctl enable --now pda`.
Windows: «Планувальник завдань» -> створити завдання при вході в систему -> дія `python pdaserver.py --run` у папці `server`.

## 7. Безпека (як це захищено)
- Усе шифрується TLS 1.2+. Застосунок підключається лише до сервера з тим сертифікатом, відбиток якого є в ключі
  (pinning). Підмінити сервер або перехопити зв'язок не вдасться.
- Користувач входить за довгим випадковим токеном. На сервері зберігається лише його хеш.
- Сервери довіряють один одному за секретом із запрошення (HMAC-перевірка, секрет по мережі не передається),
  а сертифікат іншого сервера теж перевіряється за відбитком.
- Відправника повідомлення ставить сам сервер: підробити чужий ID неможливо.
- Є ліміти: розмір повідомлення, швидкість, кількість з'єднань; після 5 невдалих входів IP блокується на 5 хвилин.
- Збережи папку `data` (там ключі, користувачі, список серверів). Файл `data/key.pem` нікому не давай.

## 8. Важливі обмеження (чесно)
- Повідомлення шифруються дорогою, але адміністратор сервера технічно може їх бачити (наскрізного шифрування
  між людьми ще немає). Довіряй тому, чий сервер використовуєш.
- Голосові дзвінки працюють лише в одній локальній мережі. Через сервер передаються текст, фото, аудіо, файли,
  геопозиції й завдання.
- Офлайн-доставка: повідомлення людині, якої немає в мережі, чекає на її сервері до 7 днів.
  Якщо сервер людини вимкнений, повідомлення не збережеться.
- Файли через сервер: до 3 МБ за раз.
